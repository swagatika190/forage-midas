# J.P. Morgan Forage - Midas Core Project

## Overview
This project simulates backend operations for the Midas Core system, including user transactions, balance queries, and Kafka integration.  
It was built as part of the J.P. Morgan Forage internship task.

## Features Completed
- UserRepository and UserRecord management
- Balance queries and transaction handling
- Kafka Producer and Consumer implemented
- Configurations for Kafka consumer
- Source code structured into clean packages: `component`, `config`, `entity`, `foundation`, `repository`

## Tech Stack
- Java 17
- Spring Boot
- Maven
- Kafka
- JUnit for testing
